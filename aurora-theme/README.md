# Introduction

Aurora is the new free & opensource NamelessMC template licensed under MIT. Constructed using FomanticUI framework and bootstrap. With being user-friendly in mind, We have dedicated template settings section where you can edit certain parts of the template without having the knowledge of HTML.

## Supported NamelessMC Releases

Aurora is compatible with latest version of NamelessMC. We are regularly updating our project on github for better User Experience.

## Supported NamelessMC Modules

Aurora has compatibility with mostly all addons that are made for NamelessMC's DefaultRevamp template.&#x20;

Modules that support Aurora's design language:

* MemberList Module
* Store Module
* Resources Module
* Infractions Module
* Ghost Module
* Newsletter Module
* Vote Module
* Suggestions Module
* Chatbox Module
* Trophies
