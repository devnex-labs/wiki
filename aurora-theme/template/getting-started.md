# Getting Started

## Installing NamelessMC

You can follow [this guide](https://docs.namelessmc.com/en/installation) to install NamelessMC on your system.

## Installing Aurora Template

1. Find latest version of Aurora from: \
   [DevNex Shop](https://devnex.pro/resources/resource/8-aurora-namelessmc-template/)\
   [Builtbybit](https://builtbybit.com/resources/aurora-theme-for-namelessmc.60813/)\
   [GitHub](https://github.com/devnex-labs/Aurora/releases)\
   [NamelessMC Resources](https://namelessmc.com/resources/resource/223-aurora-theme-\[-free-]/)
2. Open **Aurora.XX.zip** and extract contents inside `/uploads/` to the Root Directory.
3. Verify the installation by opening `/custom/templates/` directory to see if **Aurora** folder exists.
4. Now open **StaffCP** , and go to **Layout** -> **Templates**.
5. Click on **Install** button.
6. Now, click on **Activate** and set Aurora as **Default**
